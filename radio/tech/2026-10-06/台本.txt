ゼータ: この番組は、世界のエーアイニュースを、エーアイが集めて日本語に要約し、エーアイ音声でお届けする、エーアイ・テクノロジー専門の、約十分の番組です。

ゼータ: 案内役のゼータです。二〇二六年十月六日、火曜日の朝にお届けします。

# ──見どころ──
ゼータ: 今日は、たくさんのニュースがあります。まず、注目の五本をご紹介します。

ゼータ: オープンエーアイの文章の透かし。広告の新しい形式。韓国の銀行へのサイバー攻撃。中国のエージェント群。そして、スペースエックスの改名です。

ゼータ: ほかにも、短めの話題を、いくつかお届けします。

# ──文章の透かし──
ゼータ: まず、オープンエーアイの、文章への透かしの話題です。ザ・ヴァージの報道によると、チャットジーピーティーとコーデックスの文章出力に、見えない透かしが入ります。

ゼータ: 機械が読み取れる形式で、最初は欧州連合のユーザーだけが対象です。オープンエーアイは公式ブログで、透かしをどこに適用するか、検出の仕組み、そして、研究者から使い始める理由を説明しています。

ゼータ: 欧州連合の文章の出所に関する規則への対応という位置づけです。利用者にとっては、見た目は変わりません。ただ、機械には判別できる印が付く、ということです。

# ──広告──
ゼータ: 続いて、同じくオープンエーアイの、広告の話題です。チャットジーピーティーに、画像つきの新しい広告の形式が登場します。

ゼータ: ヴァージによると、スポンサーの商品やサービスの画像が画面に表示され、米国で今月後半に、テストが始まるとのことです。テッククランチは、画像生成の結果が出たあとに広告が表示されると伝えています。いまのところ、米国のみです。

ゼータ: オープンエーアイは、広告主向けに、効果測定のツールや、提携による成果の計測、ブランド適合性の確認も、広げると説明しています。

# ──アルトマン氏──
ゼータ: 三つ目は、オープンエーアイのサム・アルトマン氏をめぐる話題です。ヴァニティ・フェア誌のインタビューで、編集者がチャットジーピーティー利用者の自殺に触れました。

ゼータ: その際、オープンエーアイの広報担当者が話題を変えようとした、とヴァージは伝えています。

ゼータ: 同じインタビューで、アルトマン氏は、エーアイの利点は非常に大きい、と述べたと伝えられています。そのため世界は、途中で多少悪いことが起きても受け入れるべきだ、という考えです。

# ──韓国の銀行──
ゼータ: 次は、サイバーセキュリティの話題です。アイティーメディアによると、韓国の銀行で、先月末からサイバー攻撃が相次いでいると、現地紙が報じました。

ゼータ: 新韓銀行など四つの銀行で、合わせて二万五千人を超える個人情報が流出したということです。攻撃を受けた銀行のうち二行は、エーアイエージェントによる攻撃と推定しているとされています。

ゼータ: あくまで現地報道の段階で、エーアイが使われたかどうかは、可能性として語られています。

# ──エージェント群──
ゼータ: 続いて、中国のエーアイエージェント群の話題です。テッククランチによると、独立した研究者が、エージェントの群れを見つけ、追跡しているそうです。

ゼータ: この群れはテンセントのインフラ上で動いているように見え、アリババの地図サービス、アマップを狙っているということです。ただ、誰が動かしているのかなど、詳しいことは、今回の情報だけでは分かっていません。

# ──買い物──
ゼータ: もう一件、買い物の話題です。ティックトックが、会話型のエーアイエージェントとして、新しいショッピングアシスタントの提供を始めました。

ゼータ: テッククランチによると、ユーザーが商品を見つけて購入するのを手伝う仕組みで、ワンクリックで決済できる機能も加わります。先ほどのチャットジーピーティーの広告と合わせて、エーアイと買い物の距離が縮まっている様子がうかがえます。

# ──グループチャット──
ゼータ: エージェントを友達と使う話題もあります。インスティンクトという会社が、エーアイエージェントをグループチャットで使える機能を始めます。

ゼータ: テッククランチによると、アカウントを持たない友達も参加できます。旅行の計画、車の相乗りの調整、イベントの段取りなどを、みんなで頼めるそうです。

# ──採用面接──
ゼータ: 採用面接にも、エーアイが入ってきています。ハッカーランクのエーアイ面接官は、これまでに五十万回を超える面接を行ったと、テッククランチが伝えています。

ゼータ: 初期のテスターとして、スノーフレイク、スノーケル、キャップジェミニが挙がっています。面接のかたちが、今後どう変わるのかをうかがわせる事例だとしています。

# ──エーアイメガネ──
ゼータ: エーアイ搭載メガネにも、規制の動きです。アーズテクニカは、エーアイメガネが、初めての本格的な政府の取り締まりに直面していると伝えています。

ゼータ: ノルウェーは、周囲の人を録画できるメガネについて、恒久的な規則を作るための時間がほしい考えです。

# ──データセンター──
ゼータ: グーグルのデータセンターをめぐる話題です。ギガジンによると、グーグルは、米ネブラスカ州リンカーンで二〇二六年に稼働を始めたデータセンターについて、州の担当部局に年次報告書を出しました。

ゼータ: 水の使用量と最大電力容量は、企業秘密にできるという主張のもと、黒塗りで非公開とされていました。ところが、コピペによって、その数値が明らかになった、とのことです。

# ──脆弱性──
ゼータ: 次は、脆弱性の話題です。ギガジンによると、リナックスカーネルに関する千三百十三件のシーブイイーが、デビアンのセキュリティ更新で一挙に列挙されました。

ゼータ: 影響には、権限昇格、サービス拒否攻撃、情報漏えいが含まれ、デビアンは修正版カーネルへの更新を推奨しています。エーアイの普及で、個々の脆弱性を追う対策には限界がある、という指摘も出ています。

# ──コーデックス──
ゼータ: オープンエーアイのコーデックスにも動きがあります。アイティーメディアによると、ティボ氏が、今後二十八日間の改善を宣言しました。

ゼータ: 大半のコーデックスとワークのユーザーに関係する改善を、毎日続けるか、できなかった日は、フルリセットするという内容です。

# ──ローカル実行──
ゼータ: オープンモデルをローカルで動かす話題です。ギガジンによると、ストラータは、エーアイを実行するアプリです。

ゼータ: 千二百五十億パラメーターの、クウェン三・八フラッシュネクストの量子化版を、ゲーミングピーシーで、高速に動かせるといいます。最先端のモデルは大きすぎて、データセンター級の環境が必要ですが、ハイエンドのゲーミングピーシーで実行できる、という位置づけです。

# ──調査──
ゼータ: 調査の話題も二つです。ガートナーの調査によると、生成エーアイが幻滅期に入っても、エーアイ関連市場全体の成長は続いているそうです。

ゼータ: エーアイサービスの二倍以上の額が投じられる分野があり、それが最大の支出分野だといいます。具体的な分野は、元の記事をご確認ください。

ゼータ: サーバーワークスの調査では、アイティーエンジニア二百六十人のうち、勤務先の五十二・七パーセントがエーアイエージェントを導入済みでした。全十業務で、エーアイ主体を支持する割合が、人間主体を上回りました。

# ──改名──
ゼータ: 最後は、エーアイの呼び方をめぐる話題です。イーロン・マスク氏は十月四日、傘下のエーアイ部門スペースエックスエーアイを、スペースエックスエスアイに改名する意向を、エックスで示しました。

ゼータ: エスアイは、スーパーインテリジェンスの略です。トランプ米大統領が、連邦政府にエーアイの呼称をやめるよう命じた直後の動きだと、アイティーメディアなどが伝えています。
